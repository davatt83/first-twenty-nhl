# Football 80+ Goal Lab

Public calculator: https://davatt83.github.io/first-twenty-nhl/football-80/

This is the validated calculator checked through October 25, 2026 (America/Toronto), published from Library version 9. It includes eight leagues, team and season selection, Yes/No goal markets, and positive and negative American odds. Historical validation and the red-card prediction restriction remain unchanged.

The initial publication is a snapshot. The existing ChatGPT refresh delivers to Library and the private Site; it does not yet deliver future updates here. Replace index.html only with a successfully validated refresh and update readiness.json together. The Pages workflow checks the calculator and preserves the hockey pages. No credentials are embedded.

Run `node scripts/test-football.cjs` from the repository root to validate controls. Readiness reports distinguish the checked-through Toronto date from each league's latest accepted UTC game date.
